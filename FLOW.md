## 存储流程 (store)

```
用户消息
    │
    ▼
┌─────────────────────────────────────────────────┐
│ 1. 边界检查                                      │
│    - agentId 是否为空                           │
│    - messages 是否有效                           │
│    - db 是否已初始化                            │
└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│ 2. 消息截断                                      │
│    - 超过 MAX_MESSAGE_LENGTH (10000) 字符截断   │
└─────────────────────────────────────────────────┘
    │
    ▼
遍历每条消息
    │
    ├──▶ 跳过非 user 消息
    │
    ▼
┌─────────────────────────────────────────────────┐
│ 3. 文本归一化                                    │
│    - normalizeText()                             │
│    - 去除 @前缀、多余空白、OpenClaw 注入前缀    │
└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│ 4. 噪声过滤                                      │
│    - isNoise()                                  │
│    - 问候语、命令（/ ! -）、确认语过滤         │
└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│ 5. 精确查重                                      │
│    - content_hash SHA256 比对                   │
│    - 存在则 UPDATE access_count + last_accessed │
└─────────────────────────────────────────────────┘
    │                        ▲
    │ 重复                  │
    ▼                        │
┌─────────────────────────────────────────────────┐
│ 6. 智能去重                                      │
│    - 拉取最近 MAX_SIMILAR_CHECK (10) 条        │
│    - Jaccard 相似度计算（CJK 单字分词）         │
│    - 相似度 >= dedupThreshold → 重复            │
│    - 相似度在 [dedupUncertaintyMin, dedupUncertaintyMax] → LLM 判断
└─────────────────────────────────────────────────┘
    │                        ▲
    │ 重复                  │
    ▼                        │
┌─────────────────────────────────────────────────┐
│ 7. 核心判断                                      │
│    - isCoreKeyword() 关键词匹配（大小写不敏感）│
│    - 超过 lengthForCore (100) 触发 LLM 判断     │
│    - 设定 importance（0.5~1.0）                 │
└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│ 8. 关键词提取                                    │
│    - extractKeywords()（单字 + 英文词分词）     │
│    - 超过 lengthForExtract (200) 触发 LLM 提取  │
└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│ 9. 三层晋升                                      │
│    - getTier()                                  │
│    - peripheral ⇌ working ⇌ core               │
│    - ageDays 超标不会因为高 importance 而升 core │
└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│ 10. 写入数据库                                   │
│     - INSERT INTO memories                      │
│     - runOrThrow() 失败正常抛出                 │
└─────────────────────────────────────────────────┘
    │
    ▼
批量结束后统一 persist
┌─────────────────────────────────────────────────┐
│ 11. saveDatabase()                              │
│     - dirty list 收集所有变更，循环后一次性写入 │
│     - clearRecallCache() 清除相关缓存           │
└─────────────────────────────────────────────────┘
    │
    ▼
✅ 存储完成
```

## 召回流程 (recall)

```
用户查询
    │
    ▼
┌─────────────────────────────────────────────────┐
│ 1. 边界检查                                      │
│    - db 是否已初始化                            │
└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│ 2. 自适应检索判断                                │
│    - shouldRetrieve()                           │
│    - query.length >= minQueryLength (2)         │
│    - 包含 forceKeywords 强制触发                │
└─────────────────────────────────────────────────┘
    │                        ▲
    │ 不需要召回            │
    ▼                        │
┌─────────────────────────────────────────────────┐
│ 3. 缓存检查                                      │
│    - configHash（覆盖 9 个召回参数）             │
│    - 命中则直接返回                             │
└─────────────────────────────────────────────────┘
    │                        ▲
    │ 命中                  │
    ▼                        │
┌─────────────────────────────────────────────────┐
│ 4. 数据库查询                                    │
│    - SELECT * FROM memories                     │
│    - 按 tier / importance / access_count 排序   │
│    - 预取 safeLimit = max(20, maxResults*3)    │
│    - FTS5 MATCH 或 LIKE fallback               │
└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│ 5. 时间衰减评分                                  │
│    - tier权重（可配置，core×1.5 / working×1.0）│
│    - recencyDecay 指数衰减                      │
│    - weibullDecay Weibull 衰减（可选）         │
│    - reinforcement 访问次数强化                 │
│    - lengthNorm 长度归一化（可选）              │
└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│ 6. MMR 去重（可选）                             │
│    - mmrDeduplicate()                           │
│    - 保持多样性                                 │
└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│ 7. 硬阈值过滤（可选）                           │
│    - hardMinScore 过滤                          │
└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│ 8. 截断结果                                      │
│    - 取前 maxResults 条                         │
└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│ 9. 写入缓存                                      │
│    - set(cacheKey, result)                      │
└─────────────────────────────────────────────────┘
    │
    ▼
✅ 返回 { hasMemory, memories }
```

## 自动召回注入流程 (before_prompt_build)

```
event.messages（对话历史）
    │
    ▼
┌─────────────────────────────────────────────────┐
│ 1. 收集 user 消息                               │
│    - 提取所有 role='user' 的 content           │
│    - 取最近 3 条拼接为 query                   │
└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│ 2. Deduplication 检查                           │
│    - lastRecallKey[agentId] 对比 query         │
│    - query 与上次相同 → 直接返回，不重复注入   │
└─────────────────────────────────────────────────┘
    │                        ▲
    │ 相同                  │
    ▼                        │
┌─────────────────────────────────────────────────┐
│ 3. 自适应判断 + recall()                        │
│    - shouldRetrieve() 判断是否需要召回         │
│    - 执行完整召回流程（见上）                   │
└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│ 4. Token Budget 注入                            │
│    - estimateTokens() 估算（CKJ 按字符，       │
│      英文按 chars/4）                           │
│    - 上限 MAX_INJECT_TOKENS = 1500             │
│    - 按 importance 从高到低贪心填充            │
│    - 超出部分标注 "[...还有 N 条未显示]"       │
└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│ 5. 注入上下文                                    │
│    - api.prependSystemContext()                 │
│    - 格式：\n\n以下是相关记忆：\n[记忆] ...\n │
└─────────────────────────────────────────────────┘
    │
    ▼
✅ 记忆上下文注入完成
```

## 定时清理

```

    │
    ├──▶ 立即执行一次 cleanup()
    │
    ▼
每 DEFAULT_CLEANUP_INTERVAL_MS (24h) ──────────▶
    │
    ▼
┌─────────────────────────────────────────────────┐
│ cleanup() 执行                                   │
│                                                   │
│ cutoff = now - cleanupDays * 86400000 (ms)       │
└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│ DELETE FROM memories                            │
│ WHERE last_accessed < cutoff                    │
│   AND layer = 'general'                         │
│   AND tier = 'peripheral'                       │
└─────────────────────────────────────────────────┘
    │
    ▼
    changes > 0 ?
    │         │
    Yes       No
    ▼
 saveDatabase()
    │
    ▼

```
