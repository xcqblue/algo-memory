## 自动召回注入流程 (before_prompt_build)

有两个独立钩子：**recall 钩子**（priority 10）执行主要召回，**supplement 钩子**（priority 5）独立运行补充存储。

```
event.messages（对话历史）
    │
    ▼
┌─────────────────────────────────────────────────┐
│ 1. 收集 user 消息                               │
│    - 提取所有 role='user' 的 content           │
│    - 取最近 3 条 normalizeText 后拼接为 query  │
└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│ 2. Deduplication 检查                           │
│    - lastRecallKey[agentId] 对比 query         │
│    - query 与上次相同 → 直接返回，不重复注入   │
└─────────────────────────────────────────────────┘
    │                        ▲
    │ 相同                  │
    ▼                        │
┌─────────────────────────────────────────────────┐
│ 3. 自适应判断 + recall()                        │
│    - shouldRetrieve() 判断是否需要召回         │
│    - 执行完整召回流程（见上）                   │
└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│ 4. Token Budget 注入                            │
│    - estimateTokens() 估算                      │
│    - 上限 MAX_INJECT_TOKENS = 1500             │
│    - 按 importance 从高到低贪心填充             │
│    - 超出部分标注 "[...还有 N 条未显示]"       │
└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│ 5. 注入上下文                                    │
│    - api.prependSystemContext()                 │
│    - 格式：\n\n以下是相关记忆：\n[记忆] ...\n │
└─────────────────────────────────────────────────┘
    │
    ▼
✅ 记忆上下文注入完成
```

（已移除，存储逻辑统一由 agent_end 钩子处理，不再有独立补充钩子）

## 会话续接流程 (Session Continuity)

### 完整时序图

```
用户A 18:00 ───────────────────────────────────────────────▶
                    │
                    │ Session A (活跃)
                    │ 每次消息处理后
                    │ agent_end 触发
                    │ saveSessionSnapshot()
                    ▼
用户A 24:00 ───────────────────────────────────────────────▶
                    │
                    │ 最后一条消息
                    │ agent_end 触发
                    │ saveSessionSnapshot(A)
                    │ lastSessionKey = A
                    │ session_metadata 更新
                    ▼
04:00              │ Session A 变为 stale (每日重置)
                    ▼
用户A 07:00 ───────────────────────────────────────────────▶
                    │
                    │ 发"继续"
                    │ 检测 Session A 是 stale
                    │ 创建新 Session B
                    │
                    │ before_agent_start
                    │ detectSessionChange()
                    │ 发现 lastSessionKey(A) ≠ current(B)
                    │ 从 DB 读取 snapshot A
                    │ buildContinuityContext()
                    │ prependSystemContext()
                    ▼
                    │
                    │ AI 看到上会话摘要
                    │ 知道昨晚在讨论订机票
                    ▼
✅ 对话续接成功
```

## 定时清理

```
插件启动
    │
    ├──▶ 立即执行一次 cleanup()
    │
    ▼
每 DEFAULT_CLEANUP_INTERVAL_MS (24h) ──────────▶
    │
    ▼
┌─────────────────────────────────────────────────┐
│ cleanup() 执行                                   │
│                                                   │
│ cutoff = now - cleanupDays * 86400000 (ms)       │
└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│ DELETE FROM memories                            │
│ WHERE last_accessed < cutoff                    │
│   AND layer = 'general'                         │
│   AND tier = 'peripheral'                       │
└─────────────────────────────────────────────────┘
    │
    ▼
✅ 日志记录清理数量
```
